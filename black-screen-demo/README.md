# CZert – Čierna obrazovka
Samostatná Android app pre Android 8+.
Po *ručnom otvorení* zobrazí iba čiernu obrazovku s bielym × uprostred.
Kliknutie na × zavrie aplikáciu a presmeruje na domovskú plochu.
Systémové gestá Domov a Späť zostávajú prístupné; stránka nič nezamyká.
Bez povolení, dátového prenosu a automatického spustenia.
Zostavenie: Android Studio alebo 'gradle :app:assembleDebug'.
